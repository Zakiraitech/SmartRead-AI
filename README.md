# 🤖 SmartRead AI

SmartRead AI is a powerful cross-platform mobile application built with **Flutter** that leverages modern AI and utility services to scan, translate, and read text aloud seamlessly.

## ✨ Features
- **Smart OCR Capture:** Scan and extract text directly using your device's camera (`camera_screen.dart` / `ocr_service.dart`)[cite: 2].
- **Instant Translation:** Translate extracted text into multiple languages (`translation_service.dart`)[cite: 2].
- **Text-to-Speech (TTS):** Listen to extracted or translated text read aloud (`tts_service.dart`)[cite: 2].
- **Favorites Management:** Save important or frequently used readings for quick access (`favorites_screen.dart`)[cite: 2].
- **Cross-Platform Support:** Fully optimized to run smoothly across Android, iOS, and Web.

## 🛠️ Tech Stack
- **Framework:** [Flutter](https://flutter.dev/)[cite: 2]
- **Language:** [Dart](https://dart.dev/)[cite: 2]

## 📁 Project Structure
- `lib/screens/` - UI layers including Home, Camera, Results, Favorites, and Splash screens[cite: 2].
- `lib/services/` - Core functional handlers for OCR, translation, and TTS APIs[cite: 2].
- `lib/main.dart` - Application entry point[cite: 2].
